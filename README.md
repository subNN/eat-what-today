# 一饭为定微信小程序

## 项目简介

<p align="center">
  <img src="./icon/一饭为定.png" alt="一饭为定小程序图标" width="200" height="200">
</p>

一饭为定是一款帮助用户解决日常饮食选择困难的微信小程序，通过随机选菜和菜单管理功能，让用户不再为「今天吃什么」而烦恼。

## 功能特性

- 🎯 **随机选菜**：从自定义菜单中随机选择菜品，解决选择困难症
- 📋 **菜单管理**：创建、编辑、删除多个菜单，支持批量操作
- 💰 **价格计算**：自动计算所选菜品的总价格
- 📊 **历史记录**：保存选菜历史，方便查看和管理
- 🔄 **导入导出**：支持菜单的导入导出，方便数据备份和迁移

## 快速开始

### 开发环境

- 微信开发者工具
- 微信小程序账号

### 安装步骤

1. 克隆或下载项目到本地
2. 打开微信开发者工具
3. 导入项目，填写AppID（或使用测试号）
4. 编译并预览

## 使用说明

### 1. 首页（今天吃什么）
- 选择餐别（午餐/晚餐等）
- 选择要使用的菜单
- 点击「使用此菜单」进入菜品选择页面

### 2. 菜单管理
- 点击「创建菜单」添加新菜单
- 点击菜单进入编辑页面
- 长按菜单进入编辑模式，可批量删除
- 点击「导入导出」进行数据备份

### 3. 选择菜品
- 勾选要吃的菜品
- 点击「随机选菜」自动选择一道菜
- 调整菜品数量
- 查看总价
- 点击「保存选择」将选择保存到历史记录

### 4. 历史记录
- 查看过往的选菜记录
- 了解历史消费情况

## 技术栈

- 微信小程序原生开发
- 本地存储（wx.getStorageSync/wx.setStorageSync）
- 原生WXML/WXSS/JavaScript

## 数据存储

项目使用微信小程序的本地存储功能，所有数据存储在用户设备本地：

- `menus`：存储菜单数据
- `history`：存储选菜历史记录
- `logs`：存储操作日志
